# क्लाइंट गाइड · इंस्टॉल और सेटअप

हर कनेक्शन तरीक़े को **इंस्टॉल करके कनेक्ट करने** के चरण-दर-चरण निर्देश: Cisco AnyConnect, Hiddify, वेब प्रॉक्सी एक्सटेंशन, OpenVPN और निजी नेटवर्क (Tailscale)। साथ में: iOS पर ऐप इंस्टॉल न हो तो क्या करें, Telegram / Discord कैसे इंस्टॉल करें, कई डिवाइस एक ही बार में कैसे सेट करें, और Dropbox जैसा सॉफ़्टवेयर प्रॉक्सी माँगे तो क्या भरें। कौन-सा तरीक़ा चुनें, यह जानने के लिए [कौन-सा कनेक्शन तरीक़ा किस हालत में सही है](../network/02-choose-your-connection-method.md) देखें; इंस्टॉल हो गया पर कनेक्ट नहीं हो रहा, तो [समस्या समाधान](../troubleshooting/) देखें।
